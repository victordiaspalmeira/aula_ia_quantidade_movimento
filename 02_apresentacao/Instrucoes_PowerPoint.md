# Instruções para criar os arquivos de apresentação

1. Abra o PowerPoint (ou PowerPoint na web).
2. Use o roteiro do arquivo `Roteiro_Apresentacao_Aula_IA.md` como guia.
3. Crie de 12 a 16 slides seguindo exatamente a ordem sugerida.
4. Se estiver usando Microsoft Copilot no PowerPoint:
   - Peça para gerar a estrutura inicial com base no roteiro.
   - Depois revise slide por slide, ajustando textos e layout.
5. Salve os arquivos finais como:
   - `Apresentacao_Aula_IA_Padrao.pptx` (foco no perfil padrão: autonomia, questões objetivas, cálculo e discursiva)
   - `Apresentacao_Aula_IA_TDAH.pptx` (foco no perfil TDAH: andaimes, instruções curtas, etapas bem definidas, cronômetro por etapa)
6. Coloque os arquivos dentro da pasta `02_apresentacao/`.
7. (Opcional) Se as apresentações estiverem hospedadas no OneDrive ou Google Drive, registre o link de compartilhamento neste mesmo documento ou no README do repositório, para fácil acesso na sessão do Google Meet.
